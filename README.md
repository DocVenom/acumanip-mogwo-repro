# AcuManip-MOGWO — Reproducibility Artefacts

Supporting artefacts for the manuscript *Multi-objective evolutionary joint search of
network structure and training recipe for lightweight acupuncture-manipulation recognition*.

This repository contains **only artefacts generated by the authors**: exact split
definitions, data cards, corpus audit tables, and the per-point values behind every
figure. It contains **no raw sensor data**, for the reasons given in
[Data availability](#data-availability).

---

## What is in here

```
data/
  splits/                  exact, byte-for-byte split definitions
    ucihar_index.csv       10,299 rows — canonical order (official train then test)
    ucihar_search_split.json   3,000-sample search pool -> 2,400 search-train / 600 val
    ucihar_full_split.json     official train 85/15 -> 6,249 / 1,103
    ucihar_loso_folds.json     30 leave-one-subject-out folds
    wisdm_split.json           subjects 1-27 train / 28-36 test
  cards/                   per-dataset data cards (aggregate statistics only)
  audit/                   corpus audit of the four acupuncture datasets
results/
  figures_data/            per-point data captured from the matplotlib artists (16 files)
  constants.json           reference values that appear in figures but are not produced here
  figure_manifest.json     figure -> script -> data provenance
scripts/
  regenerate_splits.py     independently recomputes every split from the public raw data
```

## Reproducing the splits

Every split in this repository is a deterministic function of (raw data, seed).
`scripts/regenerate_splits.py` re-derives them from the public archives **without
importing any of our model code**, and asserts equality against the files in
`data/splits/`:

```bash
pip install numpy scikit-learn
python scripts/regenerate_splits.py --ucihar "UCI HAR Dataset" --wisdm WISDM_ar_v1.1_raw.txt
```

Expected output ends with `ALL SPLITS MATCH`.

### Protocol summary

| Aspect | Setting |
|---|---|
| UCI HAR search stage | 3,000 samples drawn from the official *train* split (stratified, seed 42), then split 8:2 into 2,400 search-train / 600 validation |
| UCI HAR final retraining | official *train* (7,352) split 85/15 (seed 42) -> 6,249 train / 1,103 validation |
| UCI HAR LOSO | all 10,299 samples; one subject held out per fold; 10% of the remaining subjects' data used for early stopping (seed 42) |
| UCI HAR official test | 2,947 samples, subjects 22-30 — **never** touched during search or model selection |
| WISDM windows | 128 samples @ 20 Hz, 50% overlap, cut within contiguous (user, activity) segments |
| WISDM split | subjects 1-27 train (12,090 windows) / 28-36 test (4,300 windows) |
| Normalisation | z-score statistics estimated on the training fold only |

`ucihar_index.csv` maps every sample to `(part, row, subject, label)`. Any index in the
JSON files refers to a **row of that CSV**, so the splits survive re-ordering of the
underlying archive.

## Data availability

The two public benchmarks are openly available and are **not** redistributed here:

- **UCI HAR** — DOI [10.24432/C54S4K](https://doi.org/10.24432/C54S4K), CC BY 4.0,
  30 subjects, 6 activities, 9 channels @ 50 Hz.
- **WISDM v1.1** — <https://www.cis.fordham.edu/wisdm/dataset.php>, 36 subjects,
  6 activities, 3 channels @ 20 Hz. Redistribution should carry the original `readme.txt`.

The four acupuncture corpora were obtained from the **National Basic Science Data Center
(NBSDC)** under project 2022YFB4703100. Their data-use agreement does **not** permit
redistribution by the recipient, and they contain human motion-capture and body imagery
of identifiable participants, so they cannot be hosted here. They remain available to
qualified researchers on application to NBSDC under the following CSTR identifiers:

| Dataset | CSTR |
|---|---|
| Acupuncture manipulation techniques (2.23 GB) | [16666.11.nbsdc.QutqtZMf](https://cstr.cn/16666.11.nbsdc.QutqtZMf) |
| Acupoint force and hand posture (0.54 GB) | [16666.11.nbsdc.DliwVDXs](https://cstr.cn/16666.11.nbsdc.DliwVDXs) |
| Acupoint localisation (3.78 GB) | [16666.11.nbsdc.h3Y7FJ7f](https://cstr.cn/16666.11.nbsdc.h3Y7FJ7f) |
| Acupoint knowledge graph (1.67 GB) | [16666.11.nbsdc.rt5fZiea](https://cstr.cn/16666.11.nbsdc.rt5fZiea) |

`data/audit/audit_table.json` records, for each corpus, the trial count, the number of
distinct subjects, the sampling rate, and whether any file carries a manipulation label.
That audit is the evidence behind the data-availability discussion in the manuscript:
three of the four corpora cannot support time-series classification, and only the
force/posture subset (22 trials, 4 classes) carries labels.

## Scope and limitations

- Figures' per-point data are the values actually plotted. Where a number in a figure
  comes from a published paper rather than from our runs, it is listed in
  `results/constants.json` with `reproducible_from_repo: false`.
- Model checkpoints are not included. The manuscript reports results obtained with the
  protocol above; re-running the search with the same seeds reproduces them, but the
  original weight files are not part of this deposit.
- `data/audit/audit_table.json` contains an aggregate count of distinct subject names in
  one corpus. No name, path, or per-trial identifier is included anywhere in this
  repository.
